# Security policy

## Supported version

Security fixes are applied to the current default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository when it is available. Do not disclose suspected vulnerabilities in a public issue.

Include the affected route or component, reproduction steps, impact, and any proposed mitigation. Do not include real credentials, personal data, or access tokens in a report.

There is no guaranteed response SLA for this portfolio project.
